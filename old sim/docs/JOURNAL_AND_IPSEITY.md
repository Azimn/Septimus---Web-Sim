# Septimus: private diary, source-grounded recollection, and external Ipseity

The simulation has three evidence layers that must never be silently merged. **Physical receipts** are the independent world account, dated by mechanical time. **Recollections and diary pages** are first-person, retrospective, potentially imperfect accounts and must name a verified source receipt without claiming their prose is a perfect record. **The frozen reconstructed autobiography** consists of 450 author-written fictional memories from Pretorius-Connectome v12. Those memories are period backstory, not world events newly experienced by the running simulation.

The private notebook is a physical object on the tower library's navigable map, `journal` at (7, 2). When autonomous Septimus selects `write_journal`, he must travel there. `journal_write` creates a physical receipt referencing an earlier verified event; only then can a `JOURNAL_PAGE` row be appended. The page is written in conservative first-person retrospective style, tagged `deterministic_first_person_draft`, and explicitly distinguishes testimony from physical evidence. It is not a live LLM's text, nor is it intrinsically infallible. Diary pages are append-only in the same hashed journal as world receipts and survive cold restarts. Corrections, when later supported, must be new records rather than rewrites.

The frozen 450-record corpus is vendored verbatim at `canon/Pretorius_v12_450_Events_Complete.jsonl`, sourced from `Azimn/Pretorius-Connectome` blob SHA-1 `718dcc2d5ba4feccdef1690d447edfcebaa9bfb5`. Loading checks the original Git blob digest, count, unique event IDs and reconstructed provenance, and rejects altered content. A `read_journal` goal requires reaching the same notebook. Only then is a particular folio accessed, with a `journal_read` physical receipt followed by a `FOLIO_READ` entry referencing the unchanged source's original event ID and digest. Each source folio retains its original first-person `memory_text` without rewriting its historical claims. The operator can page through the entire corpus with `GET /api/folios?offset=0&limit=10`; **this operator route does not grant the character that knowledge**. Character-facing input contains only passages the character has actually consulted.

`identity.json` remains the independent, hash-protected source for name, home, values and commitments. `src/ipseity.js` composes a read-only `externalSelf` and a `firstPersonPerception` limited to the character's current room, visible objects, bodily sensations and known observations. It cannot edit external identity and does not expose engine ticks, omniscient logistics or BeatTime. The optional local Ollama narrator gets those **character-facing** fields and already verified remembered text, not raw world state, exact mechanical timestamps or all unseen historical records. Generated narration remains tagged non-memory-eligible and contradictory narration remains logged, not allowed to change physical reality.

**Time boundary:** mechanical Swatch beats `@000..@999` belong to engine, operator UI, scheduling and external auditing. Septimus does not know these values. If a later build adds a wall clock, it must require a physically situated observation and offer an ordinary Victorian clock reading, possibly imperfect in later recollection. Even an exact observed clock must be distinguished from precise engine time. A character who has not looked at a clock cannot derive a clock time from the simulation's BeatTime or tick.

## Limitations and controlled evaluation

The current default decision policy is still deterministic, not a LLM thinking or freely writing journals. First-person diary prose is intentionally cautious templating, so this is scaffolding for subjective memory, not proof of rich autobiographical cognition. The earlier small, bounded memory/no-memory/shuffled baseline remains available and must be retested against the new diary incentives before claiming an improvement. A real memory-importance experiment would compare matched seeds for character decisions **after it reads specific pages**, with causal controls, source-linked proofs and negative outcomes preserved. Do not treat the mere presence of a journal or a model narration as functional personal memory.
