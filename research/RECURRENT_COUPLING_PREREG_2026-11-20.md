## Hypothesis and limitations

The original `Cognition.ruminate` writes a bounded thought record when a source-linked concern recurs, but `scores` does not consume those thought records. Existing world commitments and failure pressure already influence the original scorer. The test asks whether the act of rehearing/revisiting the concern adds causally distinguishable adaptive value beyond source-equivalent simple pressure. An observed choice difference is not by itself evidence of adaptation. A null is a null for this tested pathway only. No subjective-experience claims.

## Arms, held constant

A: `record_only`, original live `Cognition.ruminate`, thoughts preserved, no recurrence-to-action bonus.
B: `coupled`, same thoughts and source context, adds only a reversible bounded pressure signal to an action matching a currently open, source-linked commitment; no new action, source fact, goal, or physical authority.
C: `simple`, original live thoughts still logged but not read by the action scorer; same current commitments and series-failure facts, with a fixed bounded source-aware score adjustment. This is the equal-information, cheaper comparator, not a no-information straw man.

All use identical initialization by seed, the original world clock, physical rules, initial canon, social schedules, and same deterministic random stream. Downstream actual world receipts may diverge **because behavior diverges**; requiring identical downstream receipts would forbid a causal outcome.

## Frozen signal specification

For a currently open commitment whose action matches the scored action and whose target is still physically available:
B: use `s.thoughts` only for signed `sourceId` matching `commitment.id` or `commitment.seriesId`. Each qualifying thought contributes `6 * max(0, 1 - age / 13500)` to the utility score; sum is capped at `12.0` points. Ignore future thoughts and ages > 13500 centibeats. This source field is already generated by Cognition and retained in the canonical event journal. At most 80 recent thought records exist. An expired/completed/superseded commitment receives zero.
C: pressure = `min(12, 6 + 3 * min(2, series.brokenStreak || 0))` for the same currently open, feasible commitment, using the existing failure ledger and no thought records. This uses all facts B has access to and the same 12-point maximum. The precise temporal profile is intentionally different; it is a fair simple alternative, not a numerical clone of repeated replay.
A: no added pressure. In all arms the pre-existing `Commitments.obligationPressure` remains unchanged. Extra signal is not part of internal subjective self-report. No decision can exceed the original action affordance gate.

A/B/C signal coefficients are frozen in this file and shall not be adjusted after inspecting results.

## Design, seeds, horizons, order

Fixed seeds: 11, 12, 13, 14, 15; duration 90 days each in all three arms (15 uninterrupted simulated lives, 1,000 native ticks per day). Also run seed 11 for 365 days in each arm (3 additional uninterrupted lives), preserving the historical pre-intervention year outcome as separate external evidence. Run A, B, C for each seed in fixed order; record deterministic source/seed/policy digests. If full CI environment does not permit all runs, report completed vs missing, do not extrapolate.

Same external timed world scenario and seed. No hand-authored conversations, world rescue, extra inventory or prompts. No tuning from observed seeds. Read model-free engine source, no language model.

## Primary measurements and criterion

For each arm and seed count (not merely rates): all generated/terminal commitments, kept, broken, released and superseded, verified starts/progress, completion receipts, interruptions, resumptions, autonomous bodily preemptions, unavailable-action failures, days survived, unique completed physical action receipts, source-backed belief corrections, and dead/terminal status. Recompute all counts from the native world event journal and commitment state. Record a special 'appropriate abandonment' only if a first-class terminal status cites a verified invalidating physical circumstance. Otherwise report zero verified and not established, never infer appropriateness from a broken deadline.

Primary composite comparison B versus C: B must finish strictly more qualified commitments **without** increasing death, critical bodily preemptions, or wasted stock by more than 10% relative to C on the same seed. Do not claim a result from a single seed. Across five 90-day pairs require B to be at least as good as C in 4/5 on completed commitments, with at least one strict advantage, and no additional deaths, to justify provisional practical advantage; this is a stringent engineering gate rather than a statistical proof. A versus B tests whether coupling changes verified behavior at all.

## Harm and failure metrics

Fixation is an episode of >=6 consecutive same-commitment action selections without intervening commitment progress/completion (computed from action and goal-linked receipts), not the number of thoughts. Record fixation counts and duration.
Interruption rate numerator = `commitment_interrupted`; denominator = `commitment_progress` + `commitment_resumed` starts (report counts alongside rates).
Waste = physically receipted food or preserved spoilage quantities + recorded harvest waste; also report completed actions and resource ending balances, not unobserved consumption guesses.
Pathological outcome gate: any extra death, >10% higher spoilage/waste when C >0 (or >2 units when C=0), >20% more interruptions when C >0 (or >2 when C=0), or greater fixation incidence in B than C without higher completed obligations must be named as adverse. Do not silently smooth negative results.
