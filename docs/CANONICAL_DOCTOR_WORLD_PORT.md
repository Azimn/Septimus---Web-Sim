# Canonical Doctor world port

The pinned original Simple Tower is a source of physical and social mechanics, not a second character mind. The opt-in doctor_world mode disables the Tower's idle autonomous chooser, private rumination, fallback voice, automatic self-greeting, and player direct controls. An explicit fresh save enrolls exactly one external cognitive owner. Existing saves are not migrated or overwritten.

The trusted local Node port loads and verifies the original segmented save and exact identity/folio source. It offers only currently perceived local action opportunities and adjacent travel. It accepts a revision-bound explicit policy reference, advances real original physics, and stops when the chosen activity completes. No fallback decision is made. Repeated identical requests return their original receipt without repeating physical consequences. The port also emits a bounded first-person percept and only selected, witnessed, source-qualified event receipts. Letter claims remain testimony. This is not an authentication or operating-system sandbox; only the trusted host may invoke it.

The original scripted Rosa and Mr. McFeely, physical accounts, garden, preservation, parcels and finite goods remain in the Tower. No Village dependency is introduced. Existing psychological bookkeeping in the Tower is retained for legacy physical/scenario mechanics, not imported as canonical brain state. Not yet a full social/psychological migration: automatic settlement needs an explicit canonical action, and direct observed supplies and more nuanced economy offers need further review. This branch is a fresh-world adapter, not authorization to replace an inhabited Laboratory.

Run: node src/doctor_world_cli.js ABSOLUTE_SAVE_PATH with a JSON request on stdin: op init (epoch), observe (after cursor), or pulse (request with id, revision, choice, policyRef, steps). All requests are engineer-only. The subject receives narrative, not the packet or source IDs.
