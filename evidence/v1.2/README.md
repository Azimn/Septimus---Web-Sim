Some behaviors were tested using controlled forks; those interventions were not inserted into the unattended endurance baselines.

No simulated death mechanism exists, so no claim of seven-day biological survival is supported. The tests do not establish philosophical consciousness, generalized Article qualification, character fidelity, or long-term autonomous sustainability.
